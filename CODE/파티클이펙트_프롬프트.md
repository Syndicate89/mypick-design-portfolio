# 🌌 Hero Section 3D 우주 워프 파티클 이펙트 프롬프트

## 개요
웹사이트 Hero 섹션 배경에 우주 공간을 빠르게 이동하는 듯한 인터랙티브 파티클 이펙트를 구현합니다.
외부 라이브러리 없이 HTML5 Canvas 2D API만을 사용하여 구현합니다.

---

## 프롬프트

> Next.js (React) 프로젝트의 Hero 섹션 배경에 인터랙티브 파티클 이펙트를 구현해줘.
> 
> ### 핵심 요구사항:
> 1. **우주 워프 효과**: 화면 중앙에서 빛 입자들이 사용자 쪽(카메라 방향)으로 빠르게 쏟아져 나오는 3D 원근감 효과 (Z축 시뮬레이션)
> 2. **마우스 인터랙션**: 마우스 커서를 이동하면 파티클 흐름의 중심점(Origin)이 부드럽게 마우스 방향으로 따라감. 마우스가 없을 때는 화면 중앙에서 흐름
> 3. **유성 꼬리 효과**: 각 파티클이 이동 방향으로 늘어지듯 꼬리(streak)가 생기며, 머리 부분이 밝게 빛남
> 4. **파티클 색상**: 에메랄드 그린(#10b981, #34d399), 다크 에메랄드(#064e3b), 화이트 3가지 색상을 랜덤 배분
> 5. **반응형 파티클 수**: 데스크탑에서는 화면 픽셀 기준 최대 밀도, 모바일(768px 미만)에서는 최대 800개로 제한하여 60fps 보장
> 6. **선명한 움직임**: 블러/글로우 없이 clearRect로 매 프레임 완전 클리어하여 선명하게 렌더링
> 
> ### 세부 파라미터:
> - 파티클 기본 크기: `Math.random() * 2 + 1`
> - 이동 속도 (Z축 감소량): `9` (빠른 워프 느낌)
> - 마우스 추적 보간값(lerp): `0.12` (빠른 반응)
> - 데스크탑 입자 밀도: `(화면넓이 × 높이) / 1000`
> - 모바일 입자 밀도: `min((화면넓이 × 높이) / 1500, 800)`
> - 꼬리 두께: `max(0.5, currentSize * 0.6)`
> - 머리 크기: `max(0.5, currentSize * 0.8)`
> 
> ### 기술 스택:
> - React (`useEffect`, `useRef`)
> - HTML5 Canvas 2D API (외부 라이브러리 없음)
> - TypeScript
> - Tailwind CSS (레이아웃)
> 
> ### 레이아웃:
> - `<section>` 최소 높이 90vh, 검은색 배경
> - Canvas는 `absolute inset-0`으로 전체 배경 커버
> - 텍스트 가독성을 위한 투명 그라데이션 오버레이 (`from-black/40 via-transparent to-black/80`)
> - 컨텐츠는 `z-20`으로 파티클 위에 배치

## 조절 가능한 파라미터 가이드

| 파라미터 | 현재값 | 설명 |
|---------|--------|------|
| `speed` | `9` | 파티클 이동 속도. 높을수록 빠름 |
| `baseSize` | `random()*2+1` | 파티클 기본 크기. 증가시 입자가 커짐 |
| `밀도 분모 (Desktop)` | `1000` | 낮을수록 입자 수 증가 |
| `밀도 분모 (Mobile)` | `1500` | 낮을수록 입자 수 증가 |
| `모바일 최대값` | `800` | 모바일 성능 캡 |
| `lerp 보간값` | `0.12` | 마우스 추적 민감도. 1에 가까울수록 즉각 반응 |
| `꼬리 prevZ offset` | `9` | speed와 동일하게 유지. 늘리면 꼬리가 길어짐 |
| `꼬리 lineWidth` | `currentSize * 0.6` | 꼬리 두께 비율 |
| `머리 arc 반지름` | `currentSize * 0.8` | 머리(tip) 크기 비율 |
